Privacy policy

This policy covers "Daily Virals", a small personal tool used by the owner of the YouTube channel Trend Tamizha (@trendtamizha14) to upload the channel's own original videos, and the public "Daily Trending" links page on this website.

What the tool accesses

The tool signs in only to the channel owner's own Google account, with the owner's permission, using Google's YouTube Data API. It uses that access only to upload the channel's own videos, set their titles and descriptions, and add them to the channel's playlists.

What we collect

We do not collect, store, sell or share personal data from viewers or any other users. The sign-in token is stored only on the channel owner's own computer and is never shared with anyone.

Website

This website is hosted by GitHub Pages and has no sign-up, forms, ads or tracking of its own. GitHub may keep standard server logs; see GitHub's privacy statement.

Google API Services

Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. You can remove the tool's access at any time at myaccount.google.com/permissions.
